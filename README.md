# 30HX-Start-Stop
To enable and disable 30HX, ZOTAC's 30HX feature completely stops the fans from spinning once disabled, thereby eliminating fan noise when it's not needed.
It can automatically recognize the 30HX under Intel's integrated graphics, but this feature will not work with other configurations.
I've noticed that even when the fan stops, the graphics card seems to remain active. After a period of time, when it starts up again, the GPU temperature rises. Please test this yourself.
